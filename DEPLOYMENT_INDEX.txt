This directory now contains a complete, production-ready deployment solution
for the Ciblerh application on Ubuntu servers (20.04 LTS, 22.04 LTS, 24.04 LTS).

## 🚀 EXECUTABLE SCRIPTS (Make them executable: chmod +x *.sh)

### Primary Deployment Script
  
  📄 deploy-ubuntu.sh
     ├─ Main deployment automation script
     ├─ Installs all system services (PHP, Nginx, MySQL, Redis)
     ├─ Sets up Laravel application with all dependencies
     ├─ Configures SSL/TLS with Let's Encrypt
     ├─ Sets up queue workers with Supervisor
     ├─ Hardens security (firewall, Fail2Ban)
     └─ ~2500+ lines of production-grade code
     
     🎯 Usage:
        source deployment-config.sh
        sudo bash deploy-ubuntu.sh

### Verification & Testing

  📄 post-deployment-check.sh
     ├─ Verifies all services installed and running
     ├─ Tests database and cache connections  
     ├─ Checks queue workers operational
     ├─ Reports system resources
     └─ Provides quick reference guide
     
     🎯 Usage:
        sudo bash post-deployment-check.sh

### Backup & Restore Utility

  📄 backup-ciblerh.sh
     ├─ Creates complete database backups
     ├─ Backs up application files (excluding large directories)
     ├─ Protects .env configuration
     ├─ Supports full restore from backups
     └─ Lists available backups
     
     🎯 Usage:
        sudo bash backup-ciblerh.sh backup
        sudo bash backup-ciblerh.sh restore /path/to/backup.tar.gz
        sudo bash backup-ciblerh.sh list

### Configuration Template

  📄 deployment-config.example.sh
     ├─ Pre-built template with all required variables
     ├─ Examples for Gmail, SendGrid, AWS SES, Mailgun
     ├─ AWS S3 configuration examples
     ├─ Well-commented for easy customization
     └─ Validation checks built-in
     
     🎯 Usage:
        cp deployment-config.example.sh deployment-config.sh
        nano deployment-config.sh  # Edit your values
        source deployment-config.sh

After Deployment, Files Will Be Located At:

  Queue Workers
    /etc/supervisor/conf.d/laravel-queues.conf
    /var/log/supervisor/                # Queue worker logs

  SSL Certificates
    /etc/letsencrypt/live/yourdomain.com/
    /var/www/letsencrypt/              # Let's Encrypt challenge directory

  System Services
    /var/log/nginx/                     # Web server logs
    /var/log/mysql/                     # Database logs
    /var/run/php/                       # PHP-FPM socket

# 🔑 KEY VARIABLES - SET BEFORE DEPLOYMENT
# ==============================================================================

REQUIRED (No deployment without these):
  
  APP_DOMAIN              Your domain name (e.g., payroll.yourcompany.com)
  DB_PASSWORD             Strong password for database (generate: openssl rand -b64 32)
  MAIL_HOST              SMTP server (e.g., smtp.gmail.com)
  MAIL_USERNAME          SMTP username (e.g., your-email@gmail.com)
  MAIL_PASSWORD          SMTP password or app-specific password
  LE_EMAIL               Email for SSL certificate notifications

OPTIONAL (Have sensible defaults):
  
  APP_NAME               Application name (default: Ciblerh)
  DB_HOST                Database host (default: 127.0.0.1)
  DB_PORT                Database port (default: 3306)
  DB_NAME                Database name (default: ciblerh)
  SETUP_LOCAL_DB         Install MySQL locally? (default: true)
  REDIS_HOST             Redis host (default: 127.0.0.1)
  REDIS_PORT             Redis port (default: 6379)
  SETUP_REDIS            Install Redis locally? (default: true)
  ENABLE_SSL             Enable Let's Encrypt SSL? (default: true)
  AWS_*                  AWS S3 credentials (optional)

# ==============================================================================
# 🔧 COMMON OPERATIONS
# ==============================================================================

View Application Logs
  tail -f /var/www/ciblerh/storage/logs/laravel.log

Check System Status
  sudo monitor-ciblerh

Restart Web Server
  sudo systemctl restart nginx

Restart Application
  sudo systemctl restart php8.4-fpm

Restart Queue Workers
  supervisorctl restart laravel-queues:*

Deploy Updates
  cd /var/www/ciblerh
  git pull origin main
  composer install --no-dev
  npm install && npm run build
  php artisan migrate --force
  supervisorctl restart laravel-queues:*

Create Backup
  sudo bash backup-ciblerh.sh backup

Restore from Backup
  sudo bash backup-ciblerh.sh restore /backups/ciblerh-backup-*.tar.gz

Clear Caches
  php artisan optimize:clear
